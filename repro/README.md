# Reproduction bundle (Case A/C experiments)

The .pro input is generated by run_emag_asm.py at runtime (write_asm_pro); no pro file is bundled.

Requires: GetDP 4.0.0 + PETSc 3.25.5 (with MUMPS and SuperLU), Gmsh 4.15.2, Python 3.
GPL-licensed GetDP/PETSc binaries are NOT bundled; install per https://getdp.info and https://petsc.org.

Run (Case C sector, ~6 s/solve):
  python3 repro/run_emag_asm.py --workdir /tmp/caseC --slips 1.0 --solver mumps \
    --js-peak 3000000 --n-bars 16 --bar-diameter 3.0 --ring-radius 35.0 \
    --ring-bar-diameter 4.0 --dtheta 2.5 --sector-deg 90.0 \
    --params repro/params_js18.json

Case A threshold ladder: same command without --sector-deg, scale geometry
keys (R_si/R_rm/R_so/R_shaft/mag_t) by chi in {1.0, 1.5, 1.75, 2.0, 3.067};
force MUMPS with PETSC_OPTIONS unset, SuperLU with
PETSC_OPTIONS="-ksp_type preonly -pc_type lu -pc_factor_mat_solver_type superlu".
