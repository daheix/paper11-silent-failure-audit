# Cover Letter Draft (S6, 投稿前人工定稿)

Dear Editor,

We submit "Diagnosis and Cross-Validation Protocol for Solver-Reported
False Singularities in Frequency-Domain Magneto-Circuit-Coupled Finite
Element Analysis of Cage Induction Motors" for consideration as a Regular
Paper in IEEE Transactions on Magnetics.

Using the open-source GetDP 4.0.0 toolchain, we (1) characterize a
solver-specific false-singularity failure mode of MUMPS on
magneto-circuit-coupled cage-motor systems via a scaled threshold ladder,
including a bar-geometry confound surfaced by an independent protocol
rehearsal; (2) resolve the failure by cross-solving the identical matrix
with serial SuperLU (26 s, residual 2.28e-5); (3) quantify a
sector-symmetry contamination mechanism (fundamental inflated 1.44x,
torque 1.54x) rooted in harmonic incommensurability; and (4) distill a
five-step diagnostic protocol with both branches exercised.

All quantitative claims trace to archived raw data shipped with the
manuscript sources. The topic matches the journal's scope in computational
electromagnetics and applied numerical analysis of FE solvers, as evidenced
by recent solver-focused publications in the same venue.
